## 1. Перенести проект в PycharmProjects (5 минут)

Я работал в облачной среде, а не на твоём компьютере, и создать репозиторий в твоём аккаунте GitHub мне
не дали права интеграции. Поэтому проект лежит в папке `ai-automation-studio/` ветки
`claude/dazzling-davinci-3eqtrs` публичного репозитория `BankStatementAITest`.

```bash
# 1. Создай ПРИВАТНЫЙ пустой репозиторий: https://github.com/new  →  ai-automation-studio, Private, без README
# 2. Забери папку проекта с отдельной историей
cd ~/PycharmProjects
git clone --branch claude/dazzling-davinci-3eqtrs https://github.com/bagowix/BankStatementAITest.git _tmp-bst
cd _tmp-bst && git subtree split --prefix=ai-automation-studio -b studio && cd ..
git clone --branch studio _tmp-bst ai-automation-studio && rm -rf _tmp-bst
cd ai-automation-studio
git branch -m studio main
git remote set-url origin git@github.com:bagowix/ai-automation-studio.git
git push -u origin main
# 3. Окружение
uv sync && uv run poe hooks && uv run poe check && uv run poe tests
uv run autostudio demo-all
```

После переноса удали ветку `claude/dazzling-davinci-3eqtrs` из `BankStatementAITest`: тот репозиторий
публичный, а это твой бизнес. Секретов в ветке нет, но офферам и ценам там не место.

## 2. Решения, которые принимаешь ты (до первого клиента)

- [ ] **Модель по умолчанию.** Сейчас для Anthropic в коде `claude-opus-5-5` ($4 / $20 за 1 млн токенов).
  Под цены поддержки в брифе (Care $49 с лимитом 2 000 операций) это почти вся абонентка. `claude-haiku-5-5`
  ($0,10 / $0,50) стоит около $1 за те же операции (**П**, цены Anthropic). Порядок такой: прогони 50
  реальных писем или реплик на обеих моделях, сравни качество и выбери. Чтобы переключить клиента, впиши
  в его `.env` строку `AUTOSTUDIO_LLM_MODEL=claude-haiku-5-5`. Код при сбое модели переходит на эвристики
  (`ResilientLLM`), но качество выбираешь ты.
- [ ] **Название.** Рабочее название — «AutoStudio». Проверь, свободны ли домен `.com` в Cloudflare, имя
  в поиске Google и Instagram, нет ли похожего зарегистрированного бренда. Если занято, замени во всех
  `docs/sales/*` и `site/*` (поиск по `AutoStudio`).
- [ ] **Фокус на первые 30 дней.** Бриф ставит первым **inbox** (почта и документы), потому что у тебя
  уже есть доказательство — агент выписок со сверкой итогов. Местному бизнесу в Грузии продаётся
  **booking**. **prices** — третий. Не продавай все три всем сразу.
- [ ] **Цены.** Стартовые цены — в `docs/sales/offers.md`. После 5–10 отзывов подними на 30–50%.

## 4. Неделя 1 — ИП, платёжные каналы, аккаунты

### 4.1 ИП 🔒
- [ ] Зарегистрировать ИП в Доме юстиции: ≈ 50 GEL на следующий рабочий день или ≈ 100 GEL в день
  обращения (**НП**). Вид деятельности — **разработка ПО (NACE 62.01)**, не консалтинг.
- [ ] В тот же день подать на rs.ge заявку на **статус малого бизнеса** (1% с оборота до 500 000 GEL,
  **НП**) и дождаться, пока он появится в кабинете. Доход до получения статуса облагается по общей
  ставке 20%.
- [ ] Открыть счёт ИП (USD и GEL) и долларовую карту для оплаты сервисов: за оплату в GEL на
  зарубежных площадках банк берёт 1,5% (**НП**).

### 4.2 Платёжные каналы — по тестовому платежу $5–10 через каждый
Запиши фактические списания в таблицу. Если тест не дошёл до грузинского счёта, канал исключается.
- [ ] **Wise**: выдают ли реквизиты USD ACH и EUR IBAN; доступен ли **Wise Business** грузинскому ИП.
  Если Business нет, не принимай на Wise оплату от клиентов (**НП**).
- [ ] **PayPal Business GE**: вывод в GEL на грузинский счёт. Запиши все комиссии. По брифу —
  5,39% + $0,30 за платёж из США, 3% за конвертацию, 13,50 GEL за вывод, но есть противоречие о самой
  возможности вывода (**НП**). Принимай только коммерческие платежи (инвойс), никогда «друзьям и семье».
- [ ] **Payoneer**: комиссия за вывод USD на грузинский счёт и годовая плата (**НП**).

### 4.3 Аккаунты для работы
- [ ] **Anthropic Console** (или OpenAI): организация, оплата грузинской картой (Грузия в списке стран
  Anthropic — **П**), **лимит расходов** ниже потолка тира. Отдельный API-ключ на каждого клиента: так
  виден расход по клиенту и можно отозвать один ключ.
- [ ] **Google Cloud**: проект → сервисный аккаунт → JSON-ключ (хранить вне git). Через него пишутся
  Google Sheets клиентов: клиент просто делится таблицей с e-mail сервисного аккаунта.
- [ ] **Telegram**: у @BotFather — бот для демо и, отдельно, бот-уведомитель для тебя как оператора.
  Свой chat id узнай у @userinfobot. Впиши в `.env`: `AUTOSTUDIO_OPERATOR_BOT_TOKEN` и
  `AUTOSTUDIO_OPERATOR_CHAT_ID`.
- [ ] **Healthchecks.io** (бесплатно 20 проверок): одна проверка на каждого клиента и пакет, URL — в
  `AUTOSTUDIO_HEALTHCHECK_URL`.
- [ ] **Cloudflare**: домен `.com` (≈ $10 в год, **НП**), Email Routing на твою почту, лендинг из `site/`
  на Cloudflare Pages (инструкция в `site/README.md`). GitHub Pages для бизнеса запрещён (**П**).
- [ ] **VPS**: Hetzner CX23 (€4–6 в месяц, **НП**) или DigitalOcean / Vultr, если Hetzner откажет в
  верификации. Настройка — `docs/OPERATIONS.md`, раздел «Сервер».

### 4.4 Площадки
- [ ] **Upwork** — по `docs/sales/upwork.md`. Регистрируйся из Грузии **без VPN**, одно имя везде, заполни
  W-8BEN. В Settings → Get paid выпиши доступные способы вывода. Подай 3 проекта в Project Catalog: модерация
  у новичка занимает до нескольких недель (**НП**), поэтому подавай сразу. Если за 90 дней не будет ни
  одного отклика, профиль станет приватным (**НП**).
- [ ] **Fiverr** — по `docs/sales/fiverr.md`, только после проверки личности. Письменно спроси поддержку
  о допуске с твоим гражданством и сохрани ответ. Сделай тестовый вывод. Не больше 4 гигов.
- [ ] ⚠️ **Правило обеих площадок:** клиент, пришедший с площадки, 24 месяца (на Upwork) платит **только
  через площадку**, в том числе за ежемесячную поддержку. Telegram, e-mail или ссылки до начала
  контракта давать нельзя. Нарушение — бан (**НП**, но цена ошибки — потеря канала).

## 7. Регулярно

- **Каждый день, 5–10 минут:** сообщения ⚠️ в твоём Telegram и Healthchecks (`docs/OPERATIONS.md`).
- **Каждый месяц, 1-го числа:** отчёт каждому клиенту (`uv run autostudio report ... --format html`) вместе
  со счётом за поддержку. Клиентам с площадок счёт выставляется только на площадке.
- **Каждый месяц, до 15-го числа:** 🔒 декларация малого бизнеса на rs.ge, в том числе нулевая, и уплата
  1% (**НП**). Таблица поступлений: дата, валюта, сумма, курс НБГ на дату. Скользящая 12-месячная сумма
  по грузинским клиентам — для контроля порога НДС 100 000 GEL (**НП**).
- **Выводы с PayPal и Payoneer** делай пачками раз в месяц: фиксированные комиссии съедают мелкие суммы.
- **Обновления** зависимостей и образа — раз в месяц (`docs/OPERATIONS.md`).

## 9. Стоп-правила (из брифа, раздел 9)

| Сигнал | Решение |
|---|---|
| Верификация на площадке не прошла | Второй аккаунт не создаём, канал снимаем |
| Тестовый платёж не дошёл до грузинского счёта | Канал убираем из счетов |
| 40 откликов на Upwork без интервью | Переписать профиль, оффер и демо |
| 80 откликов без заказа | Перенести время в прямые продажи |
| 8 недель без оплаченного заказа | Сузиться до пакета inbox и одного сегмента, провести 10 интервью |
| Себестоимость клиента больше 20% абонентки два месяца подряд | Перевести на тариф выше или выставлять расходы по факту |
| Клиент хочет «ChatGPT в WhatsApp» или хранить диагнозы | Отказ: правила Meta и закон о персональных данных |
| Сайт ставит CAPTCHA, требует логин или прислал претензию | Прекращаем сбор с этого сайта в тот же день |
